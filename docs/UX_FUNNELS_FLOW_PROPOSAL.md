# UX-предложение: «Создание воронки в один флоу»

> **Проблема**: чтобы запустить одну воронку, владельцу нужно пройти 5 страниц в правильном порядке:
> `/lead-magnets` → `/funnels` → редактор шагов → `/products/{id}` для ссылки → `/funnel-triggers`.
> Каждый раз он теряет контекст («а что я сейчас делал?»), а если забыл подключить точку входа — воронка просто не запустится, и об этом нигде не написано.
>
> **Цель**: сделать так, чтобы можно было создать **полностью рабочую воронку без переходов между разделами**, но при этом не сломать существующий "разделённый" режим для опытных юзеров.

---

## 1. Текущее состояние (baseline)

Что приходится держать в голове:

```
┌─ Лидмагниты ──┐    ┌─ Воронка ──┐    ┌─ Шаги ────┐    ┌─ Точки входа ──┐
│ Загрузить PDF │ → │ Имя+TTL    │ → │ Текст+    │ → │ Ссылка ИЛИ      │
│ (заранее!)    │    │ +продукт   │    │ лидмагнит │    │ Слово ИЛИ       │
└───────────────┘    └────────────┘    │ ×N штук   │    │ default product │
       ↑                    ↑           └───────────┘    └─────────────────┘
       │                    │                 ↑                    │
       └─ если забыл —     │                  │              ┌─────┴───┐
         нужно вернуться   │                  │              │         │
                          │                   │            tracking   funnel-
                  возвращаться сюда           │            (другая    triggers
                  чтобы default_funnel        │            страница!)  (третья
                  поставить                  возвращаться                 страница!)
                                            если забыл шаг
```

5 разных контекстов. Зависимости неочевидны. Прогресс нигде не виден.

---

## 2. Главный принцип решения

> **Сделать одну страницу — "Студию воронки"** — где есть всё необходимое для запуска. Остальные разделы (`/lead-magnets`, `/funnel-triggers`) остаются как «менеджеры ресурсов» для опытных пользователей и переиспользования между воронками.

Это решает обе задачи:
- **Новички** проходят linear-флоу в одной студии
- **Опытные** могут зайти в `/lead-magnets`, массово загрузить 10 файлов, потом за минуту собрать 3 воронки

При этом сами страницы `/lead-magnets` и `/funnel-triggers` остаются — они становятся «менеджерами ресурсов» (как Photo Library в iOS):
- посмотреть все лидмагниты разом
- управлять кодовыми словами в одном месте
- переиспользовать тот же лидмагнит в новой воронке

Вот как выглядит каждая секция в студии. Это **single-page**, прокручиваемая вниз. Sticky-статус сверху всегда виден.

**Все три действия — через локальные модалки на этой же странице**:

- **«+ Новая ссылка»** → Sheet с формой UTM (utm_source, medium, campaign) → возвращает URL. Это то же что сейчас в `/products/{id}`, но без ухода со страницы воронки. `funnel_id` ставится автоматически.

- **«+ Добавить слово»** → мини-модалка «Введите слово» → POST `/api/funnel-triggers` с `funnel_id` уже заполненным.

- **«Сделать default для продукта»** → одна кнопка, делает PATCH `/api/products/{id}` с `default_funnel_id={current_id}`. Без перехода.

## 5. Что делать с `/lead-magnets` и `/funnel-triggers`

> Не убираем — они становятся **«библиотеками ресурсов»** для опытных юзеров.

### `/lead-magnets`
- Главное использование: массово загрузить пачку файлов один раз, потом переиспользовать в воронках
- Видно где каждый лидмагнит используется (новая колонка «Используется в»)
- Кнопка «Перейти к воронке» прямо из таблицы

### `/funnel-triggers`
- Глобальная таблица всех слов по всем воронкам
- Полезно когда у тебя 10 воронок и нужно проверить «а нет ли дубликата слова?»
- Можно создавать триггер не привязанный — сразу выбрать воронку из dropdown

Обе страницы сохраняют свою CRUD-функциональность, но не являются **обязательной** точкой настройки.

- Если что-то не готово — кнопка ведёт в **ту секцию студии** где надо доделать (`#section-3` якорь)

## 7. Onboarding: первая воронка через wizard

Когда юзер заходит в `/funnels` первый раз (нет ни одной воронки) — мы показываем не пустую таблицу с `<Empty>`, а **wizard** с 4 экранами:

```
┌────────────────────────────────────────────────────────────┐
│  Создание первой воронки     [● ○ ○ ○]   Шаг 1 из 4       │
├────────────────────────────────────────────────────────────┤
│                                                             │
│   Что вы продаёте?                                          │
│   ┌──────────────────────────────────────────────────┐     │
│   │ Клуб для подписчиц, 5000₽                  ⌄     │     │
│   └──────────────────────────────────────────────────┘     │
│                                                             │
│   Как назовём воронку?                                      │
│   ┌──────────────────────────────────────────────────┐     │
│   │ Воронка прогрева для клуба                       │     │
│   └──────────────────────────────────────────────────┘     │
│                                                             │
│   Сколько шагов и за какой срок?                           │
│   ┌────────────────────────────────────────────────┐       │
│   │ ○ Короткая: 3 шага за 3 дня                   │       │
│   │ ● Средняя: 5 шагов за 7 дней (рекомендуется) │       │
│   │ ○ Длинная: 7 шагов за 14 дней                │       │
│   │ ○ Пустая — добавлю шаги сам                  │       │
│   └────────────────────────────────────────────────┘       │
│                                                             │
│                              [Назад]   [Дальше: Шаги →]   │
└────────────────────────────────────────────────────────────┘
```

**4 экрана wizard'а**:
1. **Что продаём?** (выбор продукта + название + шаблон)
2. **Шаги** (готовые шаблоны с уже написанным текстом + где надо менять)
3. **Лидмагнит** (загрузка PDF на любой шаг сразу)
4. **Как привлекаем?** (создать ссылку / слово / default — минимум один)

После wizard'а — юзер попадает в **студию** (тот же `/funnels/{id}/edit`), где может уточнить детали. Wizard просто заполнил основу.

> **Принцип**: wizard — это **shortcut для первого раза**, а студия — основной инструмент. Опытный юзер пропускает wizard через «Создать пустую» в любой момент.

## 8. Приоритизация для дизайнера

Что внедрять в каком порядке — от наибольшего impact к наименьшему:

### 🔴 P0 (критично, нерешаемо без UX)

3. **Хаб `/funnels` с цветовыми индикаторами и кнопкой «Завершить настройку»** — ведёт сразу в нужную секцию.

## 9. Технические заметки для реализации

Поскольку это **не редизайн** существующих эндпоинтов, а компоновка UI:

- **Все API уже есть**: можно сделать любые внутри-страничные действия через существующие endpoints
- **Состояние страницы** удобно хранить в одном SWR-кэше: `/api/funnels/{id}` уже возвращает `steps`. Добавить надо только один лишний эндпоинт `/api/funnels/{id}/entry-points` который возвращает агрегат `{ tracking_links, triggers, is_product_default }` — но это можно делать тремя параллельными GET'ами на клиенте.
- **Wizard и студия — одна и та же страница** `/funnels/{id}/edit` в режиме «новая воронка»: показывается wizard поверх студии, после завершения — растворяется и показывает заполненную студию.
- **Анкор-навигация**: `#section-1`, `#section-2`, etc. — для smooth-scroll кликов в прогресс-баре.
- **`is_active` flag** — уже есть в модели Funnel. Добавить семантику «draft» = `is_active = false` + 0 entries.

## 10. Сравнение «было/станет» для юзера

### Сценарий: «Настроить воронку прогрева под Instagram-пост о клубе»

**Сейчас** (`6 переходов между страницами`):
1. Открываю `/lead-magnets`, загружаю PDF чек-листа
2. Перехожу в `/funnels`, создаю воронку, выбираю продукт
3. Попадаю в редактор, добавляю 5 шагов, привязываю PDF к первому
4. Возвращаюсь в `/products`, нажимаю «Изм.» на клуб, выставляю default_funnel (опц.)
5. Иду в `/products/{id}`, создаю tracking_link с указанием funnel
6. Копирую URL, иду в Instagram
7. Опционально: иду в `/funnel-triggers`, добавляю слово КЛУБ для эфиров

**Станет** (`1 переход + всё внутри студии`):
1. Открываю `/funnels`, нажимаю «+ Создать», выбираю продукт + шаблон 5-шагов
2. В студии:
   - §1: уже заполнено wizard'ом
   - §2: правлю текст шагов, к первому жму «+ Загрузить лидмагнит» — модалка с dropzone, выбираю PDF
   - §3: жму «+ Новая ссылка», заполняю utm — копирую URL
   - §3 (опц.): жму «+ Добавить слово» — пишу КЛУБ
   - §3 (опц.): жму «Сделать default для продукта»
   - §4: «Тест на меня x60» — проверяю в боте
   - §4: «Активировать»
3. Иду в Instagram с готовой ссылкой

**Сэкономлено**: 4-5 контекстных переключений. Один линейный workflow.

## 11. Что ОБЯЗАТЕЛЬНО оставить как сейчас

Чтобы не сломать привычки:

## TL;DR для дизайнера

**Сделай 4 вещи**:

1. Преврати `/funnels/{id}/edit` из «редактора шагов» в **«студию»** с 4 секциями (Параметры / Шаги / Точки входа / Запуск) и sticky-прогрессом сверху.
2. Добавь **секцию «Точки входа»** с тремя карточками — внутри них inline-модалки для создания ссылки/слова/default. Это убирает все межстраничные переходы.
3. Сделай хаб `/funnels` с **прогресс-индикаторами** в каждой карточке и кнопкой «Завершить настройку» при незавершённости.
4. Добавь **wizard для первой воронки** + кнопку «Тестовый прогон x60» в §4 студии.

Это закрывает 90% UX-проблем без переделки логики backend'а.
