# План внедрения модуля атрибуции и аналитики

План разбит на 4 фазы + сопутствующие документы. Каждая фаза самостоятельна и даёт ценность сразу после деплоя. Документы предполагают, что вы читаете их в этом порядке.

| # | Файл | Что внутри |

| 01 | [phase1_attribution.md](01_phase1_attribution.md) | **Phase 1** — миграции 001–004, tracking_links, /start-резолвер, first/last-touch, /sources |
| 02 | [phase2_funnel_products.md](02_phase2_funnel_products.md) | **Phase 2** — /funnel, /products-analytics, расширение главного дашборда |
| 03 | [phase3_subscriptions.md](03_phase3_subscriptions.md) | **Phase 3** — retention, истечения, опционально когортная матрица |
| 04 | [phase4_events.md](04_phase4_events.md) | **Phase 4** (отложено) — events-таблица, micro-conversions, KPI менеджеров |
| 05 | [backfill.md](05_backfill.md) | Скрипт one-shot восстановления исторической атрибуции |
| 06 | [testing.md](06_testing.md) | Acceptance-тесты для каждой фазы |
| 07 | [decisions.md](07_decisions.md) | Зафиксированные решения по открытым вопросам |
