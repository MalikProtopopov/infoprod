# 04. Telegram‑бот (aiogram 3)

## Multi‑bot manager
- При старте приложения и при добавлении/деактивации бота в админке управляющий компонент перезапускает polling для нужных ботов.
- Каждый активный бот → отдельная задача `Dispatcher.start_polling(bot)`.
- Реализация — `app/bot/manager.py`: словарь `bot_id → asyncio.Task`, метод `sync()` пересобирает множество запущенных ботов под текущее состояние БД.

## Хэндлеры
Единый `Dispatcher` (или один на каждого бота — для простоты по одному на бота, чтобы хранить state и токен).

Команды:
- `/start` без аргумента — приветствие + список активных продуктов (inline‑кнопки по продуктам). Записываем пользователя в `users`.
- `/start <product_code>` — сразу карточка продукта (название, описание, цены за 3/6/12 мес).
- `/my` — список активных подписок и их `ends_at`.
- `/help` — короткая справка.

Кнопки на карточке продукта:
- «Оставить заявку» → сохраняем `lead`, отвечаем «Администратор скоро свяжется».

## Сценарий выдачи доступа
Срабатывает на стороне backend (после `POST /payments`):
1. Создаётся payment + subscription.
2. `services/telegram.create_one_time_invite(bot, channel.telegram_chat_id, member_limit=1)`.
3. Сохраняем `subscription.invite_link`.
4. Отправляем пользователю сообщение через бота:
   ```
   ✅ Оплата принята.
   Доступ к каналу «<title>» открыт до <ends_at>.
   Ссылка-приглашение (одноразовая): <link>
   ```

## Сценарий отзыва доступа
- Воркер раз в час или ручное действие в админке:
  1. `bot.ban_chat_member(chat_id, user_id)` + сразу `bot.unban_chat_member(chat_id, user_id)` — пользователь удаляется и может зайти заново после новой оплаты.
  2. Подписке проставляется статус `expired` или `revoked`.
  3. Отправляем сообщение:
     ```
     ⏳ Срок доступа к каналу «<title>» истёк.
     Чтобы продлить, нажмите кнопку ниже.
     ```
     с кнопкой «Продлить» → шлёт карточку продукта.

## Антифрод‑мелочи
- Invite‑link создаётся `member_limit=1`. Повторно генерируется только если предыдущая истекла/была использована.
- Telegram user id для кика берётся из `subscription.user.telegram_user_id`.

## Тексты бота
Хранятся как константы в `app/bot/texts.py`. Замена через код. (Редактирование текстов через админку — в Приложении А ТЗ как расширение.)
