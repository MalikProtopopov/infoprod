# 00. Обзор проекта

## Назначение
Автоматизация продажи доступа в закрытые Telegram‑каналы.

Поток:
1. Клиент попадает в Telegram‑бот по ссылке (рекламной/обычной).
2. Видит карточку продукта, оставляет заявку.
3. Администратор связывается отдельным каналом, договаривается об оплате.
4. После получения оплаты администратор фиксирует факт оплаты в веб‑панели.
5. Бот отправляет клиенту одноразовую invite‑ссылку в канал и сообщает срок доступа.
6. По истечении срока подписка отзывается: бот удаляет пользователя из канала и предлагает продление.

## Компоненты
- **Telegram‑бот** — точка входа для клиента (aiogram 3, polling, поддержка нескольких ботов в одном процессе).
- **Веб‑админ‑панель** — управление ботами, каналами, продуктами, пользователями, платежами, подписками (Next.js 15 + TypeScript + Tailwind).
- **Backend API** — FastAPI, JWT‑аутентификация для админа.
- **PostgreSQL 16** — хранилище данных.
- **Фоновый воркер** — APScheduler внутри backend, ежечасная проверка истёкших подписок.
- **nginx + HTTPS** — обратный прокси, Let's Encrypt (если есть домен) или самоподписанный сертификат для IP.
